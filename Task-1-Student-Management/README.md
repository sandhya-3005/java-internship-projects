Student Management System

Description

A console-based Java application used to manage student records.

Features

- Add student details, including ID, name, and marks.
- View all registered students.
- Search for a student using their ID.
- Prevent duplicate student IDs.
- Handle invalid input.

Technologies Used

- Java
- JDK 17
- ArrayList
- Scanner

How to Run

1. Ensure JDK 17 or a compatible Java version is installed.
2. Open the project in IntelliJ IDEA.
3. Run "StudentManagementSystem.java".
4. Follow the menu options displayed in the console.
