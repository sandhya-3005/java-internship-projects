# Number Guessing Game

## Description

A console-based Java game in which the player tries to guess a randomly generated number.

## Features

* Generates a random number.
* Accepts guesses from the player.
* Provides hints to guess higher or lower.
* Tracks the guessing attempts.
* Displays the result when the correct number is guessed.

## Technologies Used

* Java
* JDK 17
* Scanner
* Random

## How to Run

1. Ensure JDK 17 or a compatible Java version is installed.
2. Open the project in IntelliJ IDEA.
3. Run `NumberGuessingGame.java`.
4. Follow the instructions displayed in the console.
