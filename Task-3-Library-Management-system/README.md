# Library Management System

## Description

A console-based Java application for managing books in a library.

## Features

* Add new books.
* Remove books from the library.
* Display available book details.
* Search for books by title or ID.
* Issue books to users.
* Return issued books.
* Track book availability.

## Technologies Used

* Java
* JDK 17
* ArrayList
* Scanner
* Object-Oriented Programming (OOP)

## How to Run

1. Ensure JDK 17 or a compatible Java version is installed.
2. Open the project in IntelliJ IDEA.
3. Run `LibraryManagementSystem.java`.
4. Follow the menu options displayed in the console.
